```ts
export type SweepInput = { runId: string; clerkOrgId: string };
export type TileStepResult =
  | SearchResult
  | { kind: 'fail'; tileKey: string; reason: FailReason; retryable: boolean; retryAfterMs?: number };

  deps: { mode: PlacesMode; shapes: GeoShapesFile }): Promise<TileStepResult>;
```
Order (research Pattern 2), for an `enterprise` search (an `ids_only` search here is a programming error → throw):
0. `await settleInFlight(ctx, search.searchId)` — a crashed earlier attempt is settled as charged before anything is called again.
1. `const first = buildFirstPage({ placesType: search.placesType, rect: search.rect, mode: 'enterprise' })`; `let req = first; let total = 0; const ids: string[] = []`.
2. For `page` 1..3:
   a. `reservePage(ctx, { searchId, page, sku: req.sku, mode: deps.mode, keyConfigured: placesKeyConfigured() })`:
      `stop` → return `{ kind:'stopped', tileKey, reason }`; `not_running` → return `{ kind:'fail', reason:'places_unavailable', retryable:false }` (finishRun's `status='running'` guard then leaves an operator's `failed` untouched); `refused` `places_key_missing` → fail `places_key_missing` non-retryable; other refusals → fail `places_request_rejected` non-retryable.
   b. `const out = await searchText(r.call, req)` — NO transaction is open during this call.
   c. `!out.ok`: `daily_quota` → `settleOrRelease(charged:false)` → return `stopped/google_daily_quota`; `rate_limited` → release → fail `places_unavailable` retryable with `retryAfterMs`; `unavailable` → release → fail retryable; `rejected` → release → fail `places_request_rejected` non-retryable; `no_key` → release → fail `places_key_missing` non-retryable; `timeout` → `settleOrRelease(charged:true)` → fail retryable; `bad_shape` → settle charged → fail `places_unavailable` non-retryable.
   d. `out.ok`: `total += out.places.length`; `ids.push(...out.places.map(p => p.id))`; build `items` in memory: `pfm = toPlaceForMatch(p, { clusterKey: search.clusterKey, queriedCity: queriedCityOf(search) })`, `hc = hostClass(p.websiteUri)`. Then ONE `withWorkerOrg` transaction: `settleInTx(tx, r.call, true)`; `tx.execute(sql.raw(similarityThresholdSql()))`; run `placeCandidatesQuery(probes, queriedCity)` (probes from the non-outside `pfm`s, `idx` = array index); group `CandidateRow`s by `idx` → `BusinessCandidate` + `name_sim` → `pfm.pureSab ? scoreSab : scoreLocated` → `decide(pfm, scored)`; `record = toPageRecord({ page, sku: r.call.sku, resultsSoFar: total, items: [...] })` with `hadWebsiteUri = hc !== 'none'`, `lat/lng` from `pfm` (null for SABs); `select app.record_places_page(${searchId}::uuid, ${JSON.stringify(record)}::jsonb)`.
   e. `if (!out.nextPageToken) break; req = buildNextPage(first, out.nextPageToken);`
3. `saturated = isSaturated(total)`. `overlap` = when `search.parentTileKey` is set: under RLS, `select m.place_id from place_tile_members m join place_tiles t on t.id = m.tile_id where t.tile_key = ${parentTileKey}` → `|ids ∩ parent| / max(1, |ids|)`; else `null`.
4. `next = decideSubdivision(search, { resultsCount: total, overlapWithParent: overlap }, shapeFor(search.shape, deps.shapes))`. On `subdivide`: `app.plan_run_searches(runId, children as jsonb with dbSafe unitId)` → merge `search_id` into each child → `PlannedSearch[]`.
5. `app.mark_run_search(searchId, { status:'done', saturated, subdivided, truncated, truncated_why })`.
6. Return `{ kind:'searched', tileKey, resultsCount: total, saturated, next }` — ids, counts, rects, enums only.
🔴 Never log a place, never put a response string in an Error, never return `ParsedPlace`. The `places`
array goes out of scope at the end of each page iteration.
