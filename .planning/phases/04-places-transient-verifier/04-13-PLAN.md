- `partitionIndex` is `currentPartition(now, tz)` for `partition`, else `null`.
- One root per (cell × type in `placesTypesFor` that passes `isTableAType`); `kind` `ids_only` for `change_check`, else `enterprise`; `quadPath 'r'`, `depth 0`, `parentTileKey null`, rect = the unit's bbox (polygon) or `circleBbox` (radius).
- `planRootSearches` throws `Error('planRootSearches: no geometry for ' + names.join(', '))` when `missingGeometry` is non-empty.
Named tests:
- `a full sweep plans one root per cell and Places type`: McAllen × home_services → 6 roots; keys `city:48215/McAllen|<type>|r` for the six types; rect = McAllen's bbox; all `enterprise`
- `a change check plans ids-only roots`
- `a partition keeps only this week's cells`: RGV baseline; for 4 consecutive Mondays (noon Chicago) the four cell sets are pairwise disjoint and their union is all 68 cells
- `a partition is the same all week`: Monday 00:30 and Sunday 23:30 Chicago of one week give the same cells
- `a radius unit is tiled from the preset's circle`: 5-mile radius at 26.2034, −98.2300 → bbox half-height ≈ 8047 m / 111320 m per degree (±1e-4)
- `a unit without geometry is named, not guessed`: the Texas 254-county spec → `missingGeometry` includes a non-RGV county; `planRootSearches` throws naming it
- `planned keys are Postgres-safe`: no `\u0000` in any `tileKey` or `cellKey`
- `every planned type is a Table A type`
