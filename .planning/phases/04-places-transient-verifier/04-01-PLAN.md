<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → repo | two new packages and their transitive install scripts |
| internet → `/.well-known/workflow/v1/*` | generated handlers; must not gain session middleware, and are reachable only through Vercel Queues in production |
| test lanes → Places | a real key in `.env.local` must never reach a test |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-15 | Tampering | `@swc/core`, `cbor-extract` install scripts | mitigate | explicit `allowBuilds` true/false each with a written reason; proven by a clean `install --frozen-lockfile` |
| T-4-14 | Spoofing | workflow internal endpoints | mitigate | proxy matcher excludes them (Pitfall 7); in production the handlers are reachable only via Vercel Queues (vercel-world docs) |
| T-4-01 | Information disclosure | test lanes | mitigate | every vitest config assigns `GOOGLE_PLACES_API_KEY='test-key-not-real'` after loading `.env.local`; CI carries no key |
| T-4-09 | Denial of service (financial) | CI | mitigate | the new lane talks to msw only; `onUnhandledRequest: 'error'` stays in the shared server |
</threat_model>
