Handler order: read headers (`x-goog-api-key`, `x-goog-fieldmask`) and JSON body → 501 on each
missing requirement (message names which) → log → `await hook?.(…)` → strip `pageToken` from the body
for route matching → first route whose `when` is true (none → serve `places-empty.json`) → error route:
serve the envelope (decrement `times`, default 1) → page route: index 0 without a token, else parse the
`:pN` suffix of `pageToken` → 501 when the page does not exist → filter each place to the fields the
mask names (`places.<field>` → `<field>`; `nextPageToken` only if masked) → `HttpResponse.json`.
Register `placesHandler` in `server.ts`'s `setupServer(...)`, and call `resetPlaces()` wherever the
shared server resets its one-shot injections after each test. Keep `onUnhandledRequest: 'error'`.
