**match.ts** (PURE; no server import; no DB):
```ts
/** Structural — the zod PlaceSchema (04-12) satisfies it without an import. */
export type PlacesResultLike = { id: string; displayName?: { text: string }; formattedAddress?: string;
  location?: { latitude: number; longitude: number }; nationalPhoneNumber?: string; pureServiceAreaBusiness?: boolean };
export type PlaceForMatch = { placeId: string; nameNorm: string | null; phone: { e164: string | null; blockable: boolean };
  address: { streetNum: string | null; streetNorm: string | null; unit: string | null; postal: string | null };
  lat: number | null; lng: number | null; pureSab: boolean; outOfArea: boolean;
  clusterKey: string; queriedCity: string | null };
export type PlaceFeatures = Features & { city?: 0 | 1; sab?: 0 | 1; listingPhone?: 0 | 1; listingLocation?: 0 | 1 };
export type BusinessCandidate = Side & { city: string | null };
export type ScoredCandidate = { businessId: string; score: number; features: PlaceFeatures };
export type MatchDecision = {
  placeId: string;
  outcome: 'attached' | 'tentative' | 'unmatched' | 'outside';
  matches: Array<{ businessId: string; score: number; status: 'attached' | 'tentative';
                   reason: 'score' | 'tie'; tieBusinessId: string | null; features: PlaceFeatures }>;
};
export function toPlaceForMatch(p: PlacesResultLike, ctx: { clusterKey: string; queriedCity: string | null }): PlaceForMatch;
export function placeSide(p: PlaceForMatch): Side;   // source 'google_places', chainKey null, locationMatchType 'overture' when located else null
export function scoreLocated(p: PlaceForMatch, b: BusinessCandidate, nameSim: number): ScoredCandidate;  // score({ a: placeSide(p), b: { ...b, chainKey: null }, nameSim })
export function scoreSab(p: PlaceForMatch, b: BusinessCandidate, nameSim: number): ScoredCandidate;
export function decide(p: PlaceForMatch, scored: ScoredCandidate[]): MatchDecision;
```
`toPlaceForMatch`: `nameNorm(displayName?.text)`; `phoneE164(nationalPhoneNumber)`; address = first
comma segment of `formattedAddress`, ZIP = the `\b(\d{5})(?:-\d{4})?\b` following `TX ` in it, fed
to `addressKey`; `outOfArea` = `formattedAddress` present and its last segment is not `USA`;
`pureSab = pureServiceAreaBusiness === true` (A8: any SAB takes the SAB branch even with a location);
lat/lng from `location`, but nulled when `pureSab` (a service area's pin is not a storefront).
`queriedCity`: folded + lower-cased city name for a city unit, `null` for county/radius units.
The returned object holds normalized KEYS only — the raw display text is not a field.

`scoreSab`: `phoneMatch = p.phone.e164 !== null && p.phone.blockable && b.phoneBlockable && p.phone.e164 === b.phoneE164`;
`cityMatch = p.queriedCity !== null && b.city !== null && fold(b.city) === p.queriedCity`
(fold = `foldDiacritics(x).toLowerCase().replace(/\s+/g,' ').trim()`).
If `phoneMatch && cityMatch && nameSim >= PHONE_LOCALITY_NAME_SIM` → score `AUTO_MERGE_SCORE`,
`features.rule = 'sab_phone_city'`; else `min(scoreLocated(p-with-null-location, b, nameSim).score, REVIEW_CEILING)`.
Always set `features.sab = 1`, `features.city = cityMatch ? 1 : 0`.
Both scorers set `features.listingPhone = p.phone.e164 ? 1 : 0` and `features.listingLocation = p.lat !== null ? 1 : 0`.

`decide`: `outOfArea` → `{ outcome: 'outside', matches: [] }`. Else sort by score desc then
businessId asc. Two or more at ≥ 95 → the top two both `tentative`, `reason 'tie'`, each
`tieBusinessId` the other → outcome `tentative`. Exactly one at ≥ 95 → `attached`, reason `score`.
Else the best in 80–94 → one `tentative`, reason `score`. Else `unmatched`, no matches.

**candidates.ts** (builds a drizzle `SQL`; executes nothing):
```ts
export type CandidateProbe = { idx: number; nameNorm: string | null; phone: string | null; postal: string | null;
  streetNum: string | null; lat: number | null; lng: number | null; sab: boolean };
export type CandidateRow = { idx: number; business_id: string; name_sim: number; name_norm: string | null;
  phone_e164: string | null; phone_blockable: boolean; street_num: string | null; street_norm: string | null;
  unit: string | null; postal: string | null; lat: number | null; lng: number | null;
  location_match_type: string | null; cluster_key: string | null; city: string | null };
export const PROXIMITY_DEG_LAT = 0.00135;   // ±150 m
export const PROXIMITY_DEG_LNG = 0.0015;    // ±150 m at RGV latitudes (cos 26° ≈ 0.899)
export function placeCandidatesQuery(probes: CandidateProbe[], queriedCityLower: string | null): SQL;
```
One statement: `with p as (select * from jsonb_to_recordset(${JSON.stringify(probes)}::jsonb) as p(idx int, name_norm text, phone text, postal text, street_num text, lat float8, lng float8, sab boolean))`
then `select distinct on (idx, business_id) …` over the union of four `cross join lateral` arms,
every arm `b.org_id = (select app.current_org_id())` and `b.merged_into_id is null`:
B1 phone (`p.phone is not null and b.phone_e164 = p.phone and b.phone_blockable`, limit 10);
B2 address (not sab; `b.postal = p.postal and b.street_num = p.street_num`, limit 10);
B3 trigram (`b.name_norm % p.name_norm`, ordered `b.name_norm <-> p.name_norm`, limit 5, scoped
`b.postal = p.postal` when not sab, `lower(b.city) = ${queriedCityLower}` when sab — the SAB arm is
omitted entirely when `queriedCityLower` is null);
B4 proximity (not sab; `b.lat between p.lat - 0.00135 and p.lat + 0.00135 and b.lng between p.lng - 0.0015 and p.lng + 0.0015`, limit 10).
Every row returns `similarity(p.name_norm, b.name_norm) as name_sim` plus the side columns above.
The caller runs `similarityThresholdSql()` first, in the same transaction (04-18).
