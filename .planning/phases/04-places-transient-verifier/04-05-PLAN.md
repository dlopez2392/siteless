**tiling.ts** (pure; no I/O; geo shapes are passed in):
```ts
export type Rect = { south: number; west: number; north: number; east: number };
export type ShapeRef =
  | { kind: 'polygon'; unitKind: 'city' | 'county'; unitId: string }
  | { kind: 'circle'; lat: number; lng: number; radiusM: number };
export type UnitShape =
  | { kind: 'polygon'; bbox: Rect; rings: number[][][] }      // [ring][point][lng, lat]
  | { kind: 'circle'; bbox: Rect; lat: number; lng: number; radiusM: number };
export type TileSpec = {
  tileKey: string;       // tileKeyOf(...) — DB-safe
  cellKey: string;       // dbSafe(clusterKey + '\u0000' + unitId)
  clusterKey: string; unitKind: 'city' | 'county' | 'radius'; unitId: string;  // unitId raw
  placesType: string; quadPath: string;  // 'r' root, then digits 0–3 per level: 'r', 'r2', 'r21'
  depth: number; rect: Rect; parentTileKey: string | null;
  kind: 'enterprise' | 'ids_only'; shape: ShapeRef;
};
export const SATURATION_RESULTS = 60, PAGE_SIZE = 20, MAX_PAGES = 3;
export const MAX_DEPTH = 5, MIN_TILE_SIDE_M = 500, NOVELTY_MAX_OVERLAP = 0.75;
export function dbSafe(s: string): string;                       // U+0000 → '/'
export function tileKeyOf(unitKind, unitId, placesType, quadPath): string;  // `${unitKind}:${dbSafe(unitId)}|${placesType}|${quadPath}`
export function isSaturated(resultsCount: number): boolean;     // === SATURATION_RESULTS exactly
export function quadrants(r: Rect): [Rect, Rect, Rect, Rect];   // 0 SW, 1 SE, 2 NW, 3 NE, split at midpoints; children partition the parent exactly
export function rectSidesM(r: Rect): { heightM: number; widthM: number };  // 111_320 m/deg lat; width × cos(mid-lat)
export function rectIntersectsShape(r: Rect, s: UnitShape): boolean;       // polygon: any ring vertex in r, OR any r corner in a ring (ray casting, holes ignored), OR any edge crossing; circle: nearest point of r to centre within radius (haversine via the repo's `distanceMeters`)
export function shapeFor(ref: ShapeRef, file: GeoShapesFile): UnitShape;    // throws naming the unit when a polygon is missing
export function circleBbox(lat: number, lng: number, radiusM: number): Rect;
export function rootSpec(a: { clusterKey; unitKind; unitId; placesType; kind; shape: ShapeRef; bbox: Rect }): TileSpec;
export type Next =
  | { action: 'done' }
  | { action: 'subdivide'; children: TileSpec[] }
  | { action: 'truncate'; why: 'max_depth' | 'min_size' | 'novelty' };
export function decideSubdivision(spec: TileSpec, obs: { resultsCount: number; overlapWithParent: number | null }, shape: UnitShape): Next;
```
`decideSubdivision` order: not saturated → `done`; `depth >= MAX_DEPTH` → truncate `max_depth`;
the smaller child side `< MIN_TILE_SIDE_M` → truncate `min_size`; `overlapWithParent !== null &&
overlapWithParent >= NOVELTY_MAX_OVERLAP` → truncate `novelty`; else `subdivide` with the quadrant
children that intersect the shape (depth + 1, quadPath + digit, parentTileKey = spec.tileKey).
If every child is pruned the result is `done` (the saturated tile's area outside the unit is not ours).

Named tests (`tests/unit/tiling.test.ts`):
- `a 60-result tile is saturated and subdivided` (M30) and `a 59-result tile is not saturated`
- `truncated at minimum size` (M31): an ~800 m square saturated at depth 1 → `{ action:'truncate', why:'min_size' }`
- `truncated at max depth`: depth 5 saturated → `max_depth`
- `novelty stops a service-area saturation loop`: saturated, overlap 0.8 → `novelty`; overlap 0.7 → `subdivide`
- `a child outside the unit polygon is pruned`: a triangle polygon covering only the SW quadrant → exactly one child, quadPath ends in `0`
- `a radius child outside the circle is pruned`
- `quadrants partition the parent exactly`: union of the four rects' areas equals the parent; shared edges are equal floats
- `tile keys never carry U+0000`: `tileKeyOf('city','48215\u0000McAllen','plumber','r')` = `'city:48215/McAllen|plumber|r'`
- `the committed geo shapes cover every seeded unit`: every city in `cities.json` and the four RGV county FIPS have an entry in `geo-shapes.json` with a non-empty ring and a bbox whose south < north and west < east

**reducer.ts** (pure, sandbox-safe — imports types only, NO Node modules, NO `@/db`, NO workflow runtime):
```ts
import type { TileSpec } from '@/lib/places/tiling';
export type PlannedSearch = TileSpec & { searchId: string };
export type StopReason = 'budget_cap_reached' | 'exceeded_estimate' | 'google_daily_quota';
export type FailReason = 'places_request_rejected' | 'places_unavailable' | 'places_key_missing';
export type SearchResult =
  | { kind: 'searched'; tileKey: string; resultsCount: number; saturated: boolean;
      next: { action: 'done' } | { action: 'subdivide'; children: PlannedSearch[] } | { action: 'truncate'; why: 'max_depth' | 'min_size' | 'novelty' } }
  | { kind: 'checked'; tileKey: string; changed: boolean }
  | { kind: 'stopped'; tileKey: string; reason: StopReason };
export type QueueState = { pending: PlannedSearch[]; searched: number; saturated: number; subdivided: number; truncated: number; stopped: StopReason | null };
export function initialQueue(roots: PlannedSearch[]): QueueState;
export function nextSearch(s: QueueState): PlannedSearch | null;              // FIFO; null once stopped
export function applyResult(s: QueueState, search: PlannedSearch, r: SearchResult): QueueState;  // returns a NEW object
export function failReasonOf(e: unknown): FailReason;   // Error whose message ∈ FailReason → it; anything else → 'places_unavailable'
export function finishVerdict(s: QueueState, failure: FailReason | null):
  { status: 'complete' | 'partial' | 'failed'; reason: StopReason | FailReason | null };
```
Named tests (`tests/unit/sweep-reducer.test.ts`): `the reducer enqueues children breadth-first`,
`a stop ends the queue`, `a truncated result counts and enqueues nothing`,
`failReasonOf maps only allow-listed keys` (an Error('SENTINEL displayName') → `places_unavailable`, never echoed),
`finishVerdict: failure beats stop beats complete`.
