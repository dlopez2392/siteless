## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> `setBudgetCap` | The cap is the ceiling on all spend; the form is the only UI path to it |
| tenant member -> the cap control | A UI that hides a button is not an access control |
| spend data -> the screen | Another tenant's figures must never appear, and a refusal must never leak one |
| this screen -> Google Cloud | There is no integration, and there must not appear to be one |
