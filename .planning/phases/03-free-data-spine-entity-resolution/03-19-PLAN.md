Build `/businesses/[id]` — every field with its source, the lead key, the merge history and the
unmerge action (D-17, D-18, D-19, D-20).

Purpose: DATA-03's visible half and DEDUP-02's reversal. 🔴 **Phase 7's triage card reuses this

inherits.

**Why source tags are text and not badges** (Executor Rule 22, and the house rule the executor
must hold): D-18 puts a source tag on *every* field — roughly ten on one screen. Ten bordered
pills is ten boxes competing with the values they annotate, and the values are what danlo is
reading. Plain muted text in a fixed column reads as a *column* rather than as ten objects,
costs no extra border colour, and cannot be mistaken for something tappable — which matters,
because D-18 says always visible, **no tap**. **Badges describe the state of a record; source
tags are metadata text. A source tag is never a badge and never an accent.**

Output: the route and five components.
</objective>

**`unmerge-dialog.tsx`** — `'use client'`. 🔴 **Unmerge is the one destructive action in this
phase and always opens its confirmation** (Executor Rule 23). `Dialog` on desk, `Drawer` on
phone via `useIsDesk()` (import it; do not write a second `matchMedia`), containing a
destructive `Alert`.

Copy is fixed in UI-SPEC § Copy Table and lives in `copy.ts`:
- Title: **"Unmerge “{loser}” from “{winner}”?"**
- Body: names all four consequences — the loser goes back to `active` with its own lead key
  {loserKey}; the winner keeps {winnerKey} and loses whatever came from the loser; the pair is
  recorded as different so nothing re-merges them automatically; and the change is recorded with
  the actor's name and the time.
- Confirm: **"Unmerge these two records"** (`business-unmerge-confirm`, destructive filled)
- Dismiss: **"Keep them merged"** (`business-unmerge-dismiss`) — 🔴 never "Cancel"

```tsx
const confirm = useCallback(() => {
  setError(null);
  startTransition(async () => {
    const result = await unmergeBusiness({ mergeId });
    if (!result.ok) { setError(result.message); return; }   // the dialog stays open
    toast(`Unmerged — “${loserName}” is active again`);
    setOpen(false);
    router.refresh();
  });
}, [mergeId, loserName, router]);
```

🔴 `onClick` inside `useTransition`, never `<form action>` — React resets a form even when the
action **failed**, and a Radix control driven by that reset walks its state backwards.
🔴 While unmerging, the confirm button shows `Spinner` + "Unmerging…" and **the dialog stays open
and modal until the server answers.**
🔴 On failure a persistent destructive `Alert` inside the dialog, not a toast: *"The unmerge
didn't complete. The two records are still merged exactly as they were — nothing was
half-undone, and both lead keys still point where they did a moment ago."* with "Try again" and
"Open sources".
🔴 **No `motion` wrapper on the Dialog or the Drawer** — Radix and vaul own those animations. Two
animation systems on one element is how a drawer ends up fighting itself.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-10 | Elevation of privilege | `unmergeBusiness` POSTed directly | mitigate | `requireOrg()` is the action's first statement and the merge row is re-read under RLS before anything is written; the dialog is not the control |
| T-3-09 | Information disclosure | `[id]` | mitigate | `isUuid()` guards the parameter; an unknown id and a foreign id are the same `notFound()`, so the response never confirms a row's existence to a wrong-tenant caller |
| T-3-13 | Information disclosure | the lead key | mitigate | Displayed and copyable but never a route parameter, never a foreign key, never a query key; a 1.07e9 namespace at 0.009 % occupancy and every lookup org-scoped by RLS |
| T-3-11 | Information disclosure | the field list | mitigate | `internal_notes` and `name_norm` are not selected by the query module and appear in no component; the leak sentinel scans every outbound builder |
| T-3-06 | Information disclosure / legal | the "Not stored" rendering | mitigate | A field whose only source would be a Google payload cannot be set at all, and the screen says so honestly rather than leaving a blank that reads as missing data |
| T-3-08 | Repudiation | the unmerge actor | transfer | Stamped by `app.undo_merge`, which reads the actor itself; the component sends only a merge id |
