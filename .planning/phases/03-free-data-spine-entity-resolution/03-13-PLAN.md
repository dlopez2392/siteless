Purpose: DATA-02. Measured against the live release on 2026-09-22:

- the naive RGV bbox (`lon ∈ [-99.30, -97.10]`, `lat ∈ [25.80, 26.75]`) materialises **98,960**

  rows — DATA-SOURCES.md's "42 % Mexico" confirmed to the decimal

  ("Hidalgo County" ×18) plus a few real city rows. **0.3 % loss, and it is the right trade**:
  admitting them would require re-admitting the 40,106 `region IS NULL` Mexican rows.

🔴 **The bucket keeps exactly one release.** `2026-08-19.0` was the only prefix under `release/`
on 2026-09-22, with `2026-09-23.0` due. A pinned release string documents provenance; it does
**not** guarantee re-fetchability. The committed fixture is the only reproducible copy.

`src/lib/overture/transform.ts` — **pure**. No `import 'server-only'`, no `fetch`, and 🔴 **no
DuckDB anywhere in its import graph**, so the test feeds it the fixture directly and CI needs no
native binary.

```ts
export const OVERTURE_RGV_BBOX = { xmin: -99.30, xmax: -97.10, ymin: 25.80, ymax: 26.75 } as const;
export function overtureRowToSourceRecord(row: unknown, release: string):
  | { skipped: 'not_texas' | 'no_name' }
  | { sourceKey: 'overture'; externalId: string; sourceVersion: string; retentionClass: 'durable'; … };
```

Two traps the transform must encode:

🔴 **1. COUNTRY FIRST.**

```ts
if (r.addr_country !== 'US' || r.addr_region !== 'TX') { return { skipped: 'not_texas' }; }
```

A region-only filter lets the three `country='MX' AND region='TX'` rows through. **M23** replaces
this with `region==='TX'` and must red two tests.

🔴 **2. DuckDB's node-api returns `VARCHAR[]` as `{ items: [...] }`, not a bare JS array.**
`row.phones.items[0]`, never `row.phones[0]` — the bare read silently produces `undefined`
phones for every row.

```ts
const phones: string[]   = (r.phones   as any)?.items ?? [];
const websites: string[] = (r.websites as any)?.items ?? [];
const socials: string[]  = (r.socials  as any)?.items ?? [];
```

Then: `externalId = r.id` **verbatim as text**, never cast to `uuid` (a bare UUID string today;
the format is Overture's to change). `nameNorm(name_primary)`, `phoneE164(phones[0])` giving
both `e164` and `blockable`, `addressKey(freeform, postcode)`, `lat = r.lat` / `lng = r.lng`
from `ST_X/ST_Y`, `basicCategory` (never `categories`), `confidence`, `operatingStatus`,
`sourceVersion = release`.

5. `release recorded` — every emitted record's `sourceVersion` equals the `release` argument.
