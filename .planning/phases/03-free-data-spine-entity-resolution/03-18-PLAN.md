<objective>
Build `/businesses` — find one record in a spine of ~92,000 (D-17).

Purpose: the focal point is **the search field**, full width at the top of the content area,
48px tall, Body 16/400 (16px is also what stops iOS zooming the viewport on focus). Autofocus on
desk only — never on phone, where it would throw the keyboard up over the list.

🔴 **Unmapped-cluster rows are visible here.** D-02 keeps them in the spine and out of the
funnel; the list shows them with the cluster cell reading **"No cluster mapped"** in
`--muted-foreground`, because a record that exists but is invisible is how a data bug survives a
quarter.

🔴 **A search that blanks its own input is the worst thing this screen could do.** The field and
the filters render immediately and stay interactive; only the rows suspend.

Output: the route and five components, plus the second entry in the `unaccent` allow-list.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `searchParams` → the search predicate | User-typed text reaches a SQL `ilike` |
| business rows → the rendered list | Untrusted third-party names are displayed verbatim |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-05 | Tampering | the search predicate | mitigate | The query string is a **bound parameter** inside `unaccent(... ilike ...)`; it never becomes SQL text, and the allow-list entry is one named file path rather than a blanket exemption |
| T-3-09 | Information disclosure | the list | mitigate | `requireOrg()` in the layout plus `withOrg` and `orgPolicies` on `businesses`; every query is org-scoped and indexed |
| T-3-11 | Information disclosure | rendered columns | mitigate | `name_norm`, `street_norm` and `internal_notes` are not selected by the query module and appear in no component, cell, tooltip or `data-` attribute |
| T-3-13 | Information disclosure | the lead key | mitigate | Searchable but never a route parameter and never a foreign key; the link href carries the internal uuid |
| T-3-03 | Tampering | verbatim names | mitigate | React escapes text by default; no `dangerouslySetInnerHTML` anywhere on this screen |
</threat_model>
