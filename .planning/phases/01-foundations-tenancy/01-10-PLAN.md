<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer machine → production database | `pnpm db:migrate:prod` runs as the owner against the real project; there is no undo |
| Vercel runtime → production database | The credential Vercel holds decides whether RLS binds on every request in production |
| repository / logs → credentials | A pasted connection string in a SUMMARY is as permanent as a committed one |
